Дата: 18 сентября 2026. Финал ≈ 9 октября. Принцип: **каждую неделю — одна вещь, которую можно показать и пощупать**, и ноль недель «на дизайн вообще».

- ИИ-сомелье: фото блюда → подбор; чат словами; Vercel-функция + Django-зеркало. **Нужен только ключ `ANTHROPIC_API_KEY`.**
- CustDev на 20 респондентов, Lean Canvas, roadmap.

## Неделя 3 (2–8.10) — «питч»

- Deck на 10 слайдов: проблема (72 % / 45 % / 80 %) → решение (30-сек демо-видео) → как работает (движок + ИИ, объяснимость) → traction (N баров, сканы, конверсия, первые ₸) → бизнес-модель (тарифы, юнит-экономика: 14 900 ₸ при цене привлечения ~1 визит) → рынок (HoReCa КЗ, Efes-канал) → roadmap → команда → ask.
- Репетиции с таймером; демо на телефоне жюри — заранее записанный fallback-видеоролик на случай Wi-Fi.
- «Killer demo» на сцене: член жюри фотографирует своё блюдо/фото на экране → ИИ распознаёт → три сорта с ценами → «Заказать» → на втором экране кабинет обновляет «эффект подбора».

## Чего НЕ делать

- Не переписывать дизайн-систему. Не менять стек. Не добавлять новые сущности (вино, коктейли) до финала — «не только пиво» решается в roadmap словами «та же архитектура: вектор напитка + вектор блюда».
- Не обещать интеграции, которых нет — показывать импорт и честный roadmap.
