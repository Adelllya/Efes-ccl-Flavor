# Каталог напитков v2

Файлы: `data/drinks.json` (412 напитков), `data/style_priors_v2.json` (132 архетипа).
Собираются одной командой, руками JSON не правим:

```
python3 scripts/build_catalog_v2.py            # собрать, проверить, записать
python3 scripts/build_catalog_v2.py --dry-run  # только собрать и проверить
```

Скрипт на стандартной библиотеке Python, результат детерминированный (повторный запуск даёт побайтно тот же файл).
В конце он проверяет всё, что требует контракт (`V2_CONTRACT.md`): обязательные ключи, оси в [0,1], архетип есть в
`style_priors_v2.json`, id уникальные и в kebab-case ASCII, 57 архетипов прототипа совпадают по числам, не-Efes ≥ 290,
всего ≥ 400. Если что-то нарушено, файлы не пишутся, код возврата 1.

## Как считается вектор

1. **Стиль → архетип.** Явная таблица в скрипте (`BEER_STYLE_MAP`, `OTHER_STYLE_MAP`), без нечёткого сопоставления.
   У каждой пары пометка точности: `exact`, `generic` (стиль указан обобщённо — «Stout», «Pale Lager», «красное сухое»),
   `fallback` (стиля нет — одна строка, Saphir Craft Beer, получает заглушку `pale_lager_intl` и статус `draft`).
   Несопоставленные стили скрипт печатает; сейчас их 0.
2. **Приор архетипа** — стартовые 14 осей.
3. **Измеримые якоря.** ABV строки → `alcohol = clamp(ABV/40)`. IBU (есть у 24 сортов) →
   `bitter = clamp((IBU−8)/62)`. Обжарочная горечь в IBU не входит, у тёмных сортов она остаётся в оси `roast`.
4. **Экспертная оценка отчёта** (только строки не-пивного отчёта и дубли). Отчёт сам пишет, что это оценка по стилю,
   а не данные источников, поэтому она не заменяет приор, а смешивается с ним: `новое = 0.5·приор + 0.5·оценка`
   (Сл/Кисл/Гор делятся на 5; тело: лёгкое .3 / среднее .5 / полное .8; газ: нет 0 / низкий .2 / средний .45 / высокий .85).
   Исключения: сладость вина, игристого и вермута — вес оценки 25 % (она уже задана категорией сахара на этикетке);
   сладость и горечь крепкого — 25 % (шкала отчёта у крепкого отражает дуб и пряность); тело воды не смешивается.
   Если IBU измерен, горечь по оценке не трогаем.
5. **Уточнения по названию стиля** (`STYLE_MODIFIERS`): milkshake IPA → dairy .15 (шкала spec §2.1), томатный гозе →
   umami .2, фруктовый витбир → сладость +.1 и т. п. Каждое — оценка и пишется в `vector_notes`.
6. **17 брендов v1**: тот же конвейер, затем пирамида нот как уточнение не больше ±0.15 на ось (spec §2.5), температура
   подачи из v1 `serving`. Пирамида уверенность не повышает — это описание, не измерение.
7. **Аромат-теги**: теги архетипа + явная таблица ключевых слов (`KW`: «яблоко» → orchard_fruit .8, «мёд» → honey .7,
   «торф» → smoke .9 …). Слова ищутся в названии, стиле и описании вкуса; теги только добавляются.

Каждое действие пишется строкой в `vector_notes` по-русски: откуда ABV, что сделал IBU, какие оси сдвинула оценка отчёта
и на сколько, какие теги добавлены, из чего сложилась уверенность.

## Если ABV не опубликован

Напиток с известным стилем не прячем из-за того, что крепость не опубликована: при известном стиле неточность ABV почти
не двигает вектор. Порядок такой:

1. Есть значение в `docs/research/ABV_SOURCES.md` — берём его. Старый Мельник из Бочонка 3.9 % (`retailer`: «Семейный»,
   MagnumOpt, mela.kz; у кеговой версии может отличаться), Kozel Světlý 4.0 % (`retailer`: Elitalco/Alco24; Kaspi даёт
   3.9 %, расхождение записано), Кружка Свежего Cranberry Hit 3.6 % (`estimate`: в ABV_SOURCES.md есть «фруктовые Hit
   3,6 %», но без отдельной ссылки на Cranberry Hit).
2. Бренд v1 без данных (кеговые Северное Сияние 4.5, Легенда 777 4.7, 13 регион 4.5, Бочковое 4.6) — документированное
   допущение v1 из `brands.json`, `abv_source: estimate`.
3. У архетипа есть диапазон ABV по BJCP (`abv_range` в `style_priors_v2.json`) — середина диапазона,
   `abv_source: bjcp_midpoint`. Например, «Pale Lager» → 2A 4.5–6 % → 5.25 %. Так 38 записей.
4. Диапазона BJCP нет (фруктовое пиво, рисовый лагер, кислый эль, портер прототипа, сидр, вино) — типичный ABV
   архетипа, `abv_source: estimate`. Так 12 записей.

Во всех этих случаях, кроме записей с подтверждённым значением (п. 1, `retailer`), стоит `flags.abv_unknown: true`
(интерфейс пишет «крепость не опубликована — принята середина стиля»), уверенность умножается на .7 (на .8 для
Cranberry Hit), в `vector_notes` написано, что именно принято. `status` остаётся `auto`.
`abv: null` осталось только у записи без стиля (Saphir Craft Beer).

## Уверенность и статус

`vector_confidence = база × ABV × IBU × стиль`, округление до сотых.

- база по якорю архетипа: BJCP .70, норматив (ЕС / ГОСТ) .65, шкала spec или архетип прототипа .60, рецептура .55,
  экспертная оценка по категории .50;
- ABV: из источника 1.0, оценка .8, не опубликован (середина стиля / допущение) .7 (для безалкогольных категорий
  с ABV 0 — 1.0);
- IBU (только пиво): измерен 1.0, нет .85;
- стиль: exact 1.0, generic .85, fallback .5.

Распределение: .2–.4 — 56, .4–.5 — 122, .5–.6 — 182, .6–.7 — 29, ≥ .7 — 23. Максимум .70 (пиво с ABV и IBU от
пивоварни). Без дегустаций выше не поднимаем.

`status: draft` означает «не знаем, что это за напиток» (стиль неизвестен). Такая запись одна — Saphir Craft Beer
(в отчёте стиль «unknown»). Остальные 411 — `auto`; неопубликованный ABV в draft не переводит.
5 позиций с `availability_kz.level: not_confirmed` (Kozel 0.0, Somersby Pear, Strongbow, «аргентинский мальбек»,
«молдавское вино») остаются в каталоге с `flags.availability_unconfirmed`; гостю их не показываем (spec §8.3).
4 записи — не SKU, а типовые позиции винной карты (`flags.generic_position`).

## Архетипы (`data/style_priors_v2.json`)

57 архетипов прототипа — числа те же, ключи переименованы по контракту (carb → carbonation, aroma → aroma_intensity,
temp → serve_temp, alcohol = clamp(abv/40)). Изменены только теги вне словаря контракта: у ячменного вина `toffee` слит
в `caramel`, у чёрного чая удалён `tannic` (это ось), у янтарного лагера origin `austrian` → `german`; записано в `notes`.

75 новых архетипов (пиво 21, б/а пиво 3, сидр 1, вино 4, игристое 2, вермут 2, ликёры 5, крепкое 8, коктейли 11,
молочные 4, злаковые 2, сок 1, газировки 4, вода 2, чай 2, кофе/какао 3), у каждого `anchor` и `anchor_type`:

- 18 пивных с vital statistics BJCP 2021 (`anchor_type: bjcp`): 1B, 2C, 3A, 5B, 5C, 8A, 9A, 10B, 11B/11C, 12C, 18A,
  21C, 23G, 25A, 25C, 26B, 26C, 27A. Ещё 3 (кислый эль, сладкое фруктовое, пиво с дубом) — экспертные: у BJCP 23A,
  29A, 33A фиксированных цифр для них нет. У 5 архетипов прототипа (amber_lager, american_pale_ale, brown_ale,
  milk_stout, kriek_sour) якорь дополнен сверенными 7A, 18B, 13B, 16A, 23F. Всё сверено на bjcp.org 22.09.2026,
  ссылка в поле `verified`. Горечь — по формуле §2.1 от середины IBU, кроме hazy IPA (.45 вместо .55: BJCP
  «perceived bitterness, often masked by the fuller body»).
- Вино и игристое по категории сахара (8, `regulation`): регламент ЕС 2019/33, прил. III (extra dry 12–17 г/л,
  dry 17–32 г/л; «dry» до 4 г/л, «medium dry» до 12 г/л, «medium» до 45 г/л). Вермут: регламент ЕС 251/2014, ст. 6.
  Сверено по legislation.gov.uk (текст регламентов ЕС) 22.09.2026.
- Коктейли — по рецептуре (10, `recipe`); ABV в бокале — оценка рыночного отчёта.
- 5 опираются на шкалы spec §2.1 (сливочный ликёр dairy .8, амаро, тоник, эспрессо, Bloody Mary).
- Остальные 34 (крепкое, ликёры, национальные напитки, безалкогольное) — «экспертная оценка по категории», это прямо
  написано в `anchor`.

Числа новых архетипов — интерполяция между соседними архетипами прототипа по указанному якорю. Дегустацией не проверены.

## Как сомелье правит напиток

Правки лежат отдельно от генерируемого файла, чтобы пересборка их не стирала. Создайте `data/drink_overrides.json`:

```json
{
  "carlsberg": {
    "vector_override": {"bitter": 0.30, "body": 0.30},
    "reviewed_by": "Иванов И., дегустация 2026-10-01",
    "note": "слепая дегустация, 3 образца"
  }
}
```

и пересоберите каталог. Скрипт запишет `vector_override` в запись, подставит значения в `sensory`, поставит
`vector_source: sommelier_override`, `status: reviewed`, поднимет уверенность до .8 и добавит строку в `vector_notes`.
Движок применяет `vector_override` последним. Начинать разумно с записей `auto` с уверенностью ниже .6 (их 359)
и с самых продаваемых: массовые лагеры KZ сейчас почти не отличаются друг от друга, потому что у них нет IBU.

## Решения, о которых стоит знать

- Стили CIS-лагеров «мягкое / Light» сопоставлены с BJCP 1A (Light Lager), как указано в отчёте. Возможно, ближе 1B.
- Kozel Světlý и Slavna Praga — BJCP 3A (Czech Pale Lager, 3–4.1 %), а не премиальный пилзнер 3B.
- «Pale Lager», «Pale Lager (draft)», «Жигулевское» — международный светлый лагер 2A с пометкой generic.
- Miller Genuine Draft: 4.4 % по ABV_SOURCES.md (локальный розлив), хотя в рыночном отчёте 4.7 %.
- Кеговые сорта Efes без опубликованного ABV (Северное Сияние, Легенда 777, 13 регион, Бочковое) — допущение v1,
  `flags.abv_unknown`, статус `auto`. Kozel Světlý — `retailer` 4.0 % при расхождении с Kaspi (3.9 %).
- Середина стиля — это середина диапазона BJCP (2A 4.5–6 % → 5.25 %), а не типичная крепость KZ-лагеров: у 19
  казахстанских 2A-лагеров каталога с известным ABV медиана 4.6 %. Для 13 светлых сортов без ABV (Шымкентпиво,
  Первый Пивзавод, Baza, Любительское, Тянь-Шань и др.) принятое значение, скорее всего, завышено примерно на 0.6 %;
  на векторе это −.015 по оси alcohol.
- Somersby отмечен `labeled_as: «пивной напиток»` по ключевому выводу отчёта (солодовая основа в KZ).
- Строки из нескольких продуктов («Fanta / Sprite / Schweppes», «Pepsi / 7Up / Mirinda») оставлены одной записью, как
  в отчёте, — не дробим, чтобы не выдумывать отдельные профили.
- Kaspi как источник цены не засчитывается: отчёт пишет, что цены Kaspi не отображаются.
- Ссылки, данные в отчёте только доменом («kaspi.kz») или сокращённые с «…», указывают на корень домена (78 ссылок);
  внутренние материалы Efes — `internal:Flavor_Tree_Beer_Data_Draft.md`; для Ulydala URL собран из хэндла Instagram.

## Известные пробелы

- Ни одной дегустации: все оси, кроме alcohol и bitter у 24 сортов, — приоры и оценки.
- IBU нет у всех массовых лагеров, включая 17 брендов Efes. Официальный продуктовый лист Efes (ABV, экстрактивность,
  IBU) закрыл бы это для портфеля сразу (см. ABV_SOURCES.md §6).
- У 56 записей ABV не опубликован (крафт Алматы/Астаны, разливные сорта, Line Brew, Шымкентпиво) — принята середина
  стиля или допущение, см. «Если ABV не опубликован».
- Цены HoReCa в основном из одной барной карты Алматы (restolife.kz) и «уровня цен» обзоров; розница — alco24, Elitalco.
- Efes 0.0 Абрикос-Малина по карточке MagnumOpt 0.6 % — выше порога 0.5 %, поэтому `flags.non_alcoholic: false`.
- Квас: ABV 1.2 % — типичное значение категории, не из источников. Sigma Kvass по сайту 0.0 %.
- Вина Bacchus, Turgen, Arba: ABV типовой для сорта (производители его не публикуют).
- Не использовано 8 архетипов прототипа (barleywine, brut, demi-sec, mezcal, red_light, riesling, shiraz, soda_water):
  таких SKU в отчётах нет. Добавлять их без проверенного источника не стали.
