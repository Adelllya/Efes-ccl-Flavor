## 1. Изменение модели `Brand` — добавить упаковку

В модель, которую я описывал в промпте для Arena AI, нужно добавить поле:

```python
class Brand(models.Model):
    ...
    PACKAGING_CHOICES = [
        ('BOTTLE', 'Бутылка'),
        ('CAN', 'Банка'),
        ('DRAFT', 'Разливное'),
    ]
    packaging_type = models.CharField(max_length=10, choices=PACKAGING_CHOICES)
    is_horeca_only = models.BooleanField(
        default=False,
        help_text="Доступно только в заведениях HoReCa (обычно = True для разливного)"
    )
```

Логика: если `packaging_type == 'DRAFT'` — по умолчанию `is_horeca_only = True` (можно сделать это через `save()` override или просто выставлять вручную в fixture). Разливное обычно не продаётся в рознице/на маркетплейсах, только в барах/ресторанах — это важно для будущего HoReCa-модуля (QR-меню должно показывать в первую очередь разливные позиции конкретного заведения).
