# Flavor Tree — матрица Food Pairing (51 пара)

По 3 пары на каждый сорт пива, подобраны по логике из roadmap: **complement** (похожие вкусы усиливают), **contrast** (противоположности уравновешивают — жир+горечь), **cleanse** (пиво освежает после тяжёлого/острого), **bridge** (общая конкретная нота — например дым/карамель).

⚠️ Черновик на основе вкусовых пирамид-заготовок — сомелье может скорректировать после реальной дегустации.

## Формат для CSV-импорта (`FoodPairing`)

```
brand_name,dish_name,compatibility_score,pairing_type,explanation
Кружка Свежего,Баурсаки,3,complement,"Нейтральный вкус выпечки не спорит с простым лагерным профилем"
Кружка Свежего,Куырдак,4,contrast,"Свежесть пива освежает жирность жареных потрохов"
...
```

Поле `pairing_type` — строго одно из: `complement` / `contrast` / `cleanse` / `bridge` (нижний регистр, как в модели).

Загружается тем же принципом, что и `brands_seed.csv` — через management command (например `load_food_pairings`), который матчит по `brand_name`/`dish_name` и создаёт `FoodPairing` записи с FK на уже существующие `Brand`/`Dish`.

## Что дальше

Это первая волна — по 3 «якорных» пары на сорт (то, что попадёт в UI как топ-рекомендации). Остальные комбинации из полной матрицы 17×50 можно не заполнять вручную — Ералы позже допишет автоматический скоринг по совпадению атрибутов (`dominant_taste`, `fat_level`, `weight` блюда ↔ доминирующие ноты base-слоя пива), а вручную остаются только премиум-пары с осмысленным объяснением, как здесь.
